# AI 學術關鍵字卡產生器

## 專案簡介

本專案是一個代表個人學習與報告準備流程的自動化工具。使用者只需要輸入學術或課堂常見關鍵字，系統即可產生中文名稱、名詞解釋、應用情境與報告可用句型。

## 網頁展示

GitHub Pages 連結：

https://ruuuuu0415-hub.github.io/Skill-academic-keyword-card-generator/

## 專案目的

在準備課堂報告或期末作業時，學生常需要整理大量專業術語。若每個名詞都手動查詢與整理，容易耗時且格式不一致。因此本作品透過網頁工具與 Python 程式，建立一個關鍵字卡片產生器，協助使用者快速完成術語整理。

## 核心功能

1. 輸入學術關鍵字
2. 選擇課程或應用領域
3. 產生中文名稱
4. 產生名詞解釋
5. 產生應用情境
6. 產生報告可用句型
7. 複製或下載結果
